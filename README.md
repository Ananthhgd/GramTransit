# GramTransit

GramTransit is an open-source, public-service transit application suite designed to provide reliable bus timings for rural village routes. It focuses on accessibility, low-bandwidth resilience, and multilingual support for rural passengers.

## Component Status

- **Passenger app**: In development (`gramtransit_passenger/`)
- **Driver app**: Planned
- **Admin app**: Planned
- **Backend**: Planned

## Repository Layout

- `gramtransit_passenger/`: The primary Flutter mobile application for passengers.
- `docs/`: System-level documentation and Architecture Decision Records (ADRs).
- `.github/workflows/`: CI/CD automation for components.
